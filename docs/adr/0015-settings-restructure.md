# 设置重构：顶栏图标化、三页签设置、主页面致密化

#34 主页面与设置对话框的布局重构：顶栏移除语言切换、设置入口图标化；设置
对话框从两页签扩为三页签（通用 / Steam / 关于），原 General 的「关于」区拆解
（应用更新 + 项目主页 GitHub 入口 + 设置向导聚为「关于」页签）；补丁更新入口
回主页面；语言改下拉；主页面致密化并新增底部状态显示栏。

> 取代 ADR-0010 的顶栏对齐约定（设置 + 语言切换 72×28 Neutral、语言最右）：
> 本 ADR 生效后顶栏只剩齿轮设置入口（28×28 Neutral），语言切换入口移除，
> 语言选择收拢到设置通用页签下拉与向导步骤 1。ADR-0010 的语义色板部分不变。

## 为什么这样重构

- **顶栏语言切换是冗余入口**：语言本属设置；移除后改语言唯一入口收拢到
  「设置 → 通用」与向导。设置入口用通用符号（齿轮）+ tooltip，对误入错误语言
  的用户是可发现性兜底。
- **「关于」是天然的主题聚合**：软件版本、应用更新检查、项目主页、设置向导
  都是"关于本工具"的信息，聚成一页比散在通用页签清晰；GitHub 入口做成含
  mark 的链接按钮（悬停显示完整 URL），比完整 URL 按钮轻。
- **补丁更新入口回主页面**：补丁与部署状态同语境，放部署状态卡片内（单按钮，
  检查/下载共用按钮位）比藏在设置里更可达；结果文案内联于按钮右侧，不进状态栏。
- **语言三态改下拉**：三选一单选组占三行，下拉一行收起；设置与向导共用同一份
  选项表（跟随系统 / 简体中文 / English），未来加语言只改一处。
- **状态信息互不覆盖**：底部状态显示栏多条并排、各自独立成项（Steam 运行状态
  恒显示 + 忙碌 + 最近操作结果），色点语义只走既有语义槽，不引入新色。

## 决策

- 顶栏只留齿轮设置入口；齿轮为**最初版式**（圆环 + 8 颗圆齿 + 中心点，程序化
  绘制、色值走语义色板）；`toggle_lang`、`Language::toggled`、`toggle_label`
  一并删除，不留死代码。
- 设置对话框三页签顺序：通用（语言下拉 + 主题 + 系统托盘）/ Steam（路径编辑 + 兼容性小节）/
  关于（软件版本 + 应用更新检查 + 项目主页 GitHub 链接按钮 + 设置向导）。
- 系统托盘偏好收拢到通用页签（#37 修订）：新增「系统托盘」小节，含「最小化时隐藏到系统
  托盘」勾选框；与托盘菜单勾选项共用 `config.toml` 的 `minimize_to_tray` 同一事实源，
  任一入口变更即同步另一入口并持久化，启动时按持久化值恢复两处勾选态。解析为字段级宽容
  （#35 Q5 读法 B）：字段缺失或类型非法均降级默认启用，不拖垮整份配置的其他字段。
- 深浅主题偏好收拢到通用页签（#39 / ADR-0016 修订）：新增「主题」小节，三态下拉
  （跟随系统 / 深色 / 浅色），与语言下拉同布局；即改即存、即时生效，config 新增 `theme`
  字段（宽容解析，缺省跟随系统，老配置缺字段不迁移不 bump 版本）。
- 应用更新与补丁更新两条链路「只搬不合」：入口、比较基准（crate 版本 vs
  `dlls/version.txt`）与结果文案维持 ADR-0014 的严格区分；应用更新结果内联于
  按钮右侧。
- 兼容性小节：徽章行 = 徽章在左 + 「详细信息/预热」贴最右；状态说明收进
  「详细信息」展开内（置于徽章行正下方）；点击展开后滚动到明细可见（steamclient64.dll
  (IPC) 等行），无需手动滚动。
- 主页面：部署状态 16px bold + 补丁更新按钮（方案 B，检查/下载共用按钮位，
  结果内联右侧）；操作按钮 44px 高、14px 字号（`styled_button` 字号按高度派生）；
  底部状态显示栏 = Steam 运行状态（恒显示）+ 忙碌 + 最近操作结果，多条并排互不
  覆盖；窗口维持首帧自适应（#32 的 `autosize_inner_height` 下限不变）。
- 向导步骤 1 语言下拉选中即本地化但不推进，点「下一步」才进步骤 2
  （`LanguageSubmitted` 事件）。
- **设置对话框间距（用户验收微调，覆盖早期默认）**：Modal 显式 frame（内边距
  24/20 lp + 1px 边框；egui 默认 menu_margin 6lp 太贴边）；内容区行距 13lp
  （全局默认 10lp），页签/分割线/页脚段间距 12–16lp。`SETTINGS_DIALOG_SKELETON_H`
  随 frame 内边距上调同步（208 → 236），首帧自适应下限随之提升，设置页脚在最小
  自适应窗口内仍可见（有守卫测试）。
- 发布流程补版本同步：`tools/build-release.ps1` 打包前把 Cargo.toml 的 version
  字段改为发布版本（修 0.2.4 陈旧版本号 + 应用更新检查永远报新版的问题）。

## 否决的方案

- 顶栏保留语言切换（冗余入口，与「单入口一致性」冲突）。
- 用 ⚙ 字形 / 打包图标字体做设置图标（字形依赖字体覆盖、新增依赖；程序化绘制
  零依赖且永不豆腐块）。
- 齿轮候选中的经典齿轮、实心齿轮、细线齿轮、螺丝头、滑块等方案（多轮比选后
  用户最终回到最初版式；细线 28px 糊成圆块、螺丝头读成关闭 X、滑块 28px 不可读）。
- 向导步骤 1 保留大按钮（两处入口形态不一致，多语言后不可扩展；用户要求同改）。
- 补丁更新入口方案 A（顶栏）/ C（独立行）/ D（并入操作区）未选——B 与部署状态
  同语境最符合心智。
- 应用更新/补丁更新结果换行置底（与按钮右侧内联相比更占空间）；补丁结果放底部
  状态栏（与操作结果混置，用户要求移出）。
- 「更新」页签中间形态（应用更新 + 补丁更新同页）未保留——补丁更新回主页面后，
  剩余内容并入「关于」。

## 验收

- 顶栏无语言按钮；齿轮（最初版式）点击打开设置（tooltip 双语）。
- 设置对话框三页签 通用/Steam/关于；通用页签含语言下拉、「主题」小节（三态下拉，
  即改即存即时生效）与「系统托盘」小节（最小化隐身勾选框，勾选即改即存）；关于页含版本行 + 应用更新检查（结果内联）
  + GitHub mark 链接按钮（悬停显 URL）+ 设置向导；Steam 页签兼容性小节徽章在
  左、操作贴右，说明在「详细信息」展开内，展开后滚动到明细可见。
- 托盘菜单「最小化时自动隐藏到托盘」勾选与设置通用页签勾选双向同步、共持久化
  （#37；启动按 config.toml 恢复，老配置缺字段默认启用）。
- 语言下拉（设置 + 向导）选项 = 跟随系统 / 简体中文 / English，与其他按钮同底；
  向导选中不直达、点「下一步」推进。
- 主页面部署状态卡片含补丁更新按钮（检查/下载共用按钮位，结果内联右侧）；底部
  状态栏 Steam 状态恒显示，与忙碌/操作结果并排互不覆盖。
- `cargo test --workspace` / `cargo check --workspace --all-targets` /
  `cargo clippy --workspace --all-targets` / `cargo fmt --all --check` 全绿；
  齿轮、状态栏、兼容性明细滚动为人工验证项。

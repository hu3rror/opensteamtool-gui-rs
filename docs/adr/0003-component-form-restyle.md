# 组件形态对齐旧版 GUI（component-form parity restyle）

> 配色部分已被 ADR-0010 取代「统一语义色板」：逐按钮色值清单不再维护，具体色值以 0010 槽表为准；本 ADR 保留的决策是组件形态（accent bar、独立按钮区、纯文字状态、kill-ai-slop 红线）。

## 背景

本版外观沿用旧版 GUI 的视觉基准：最终用户已习惯其组件形态，重写时全面沿用，替换 ADR-0002 中 Apple-inspired 的配色与组件形态。

## 决策

- **卡片标题**：标题左侧 3px 蓝色 accent bar（色值现由 ADR-0010 accent 槽派生），替代纯文字标题。
- **操作按钮区**：卡片 2 与卡片 3 之间的独立等宽双按钮区。
- **状态展示**：纯文字行——`【已应用】…`（绿）/ `【未应用】…`（灰），无圆点徽章；Steam 运行与否通过按钮文案（「退出 Steam 并卸载补丁 / 卸载补丁」）体现。
- **版本信息**：卡片 3 纯文本行（`当前本地版本：…` / `最新线上版本：…` + 状态后缀），非胶囊标签。
- **文案**：状态术语统一「已应用/未应用」（见 CONTEXT.md）；按钮保留 ▶/◀ 前缀；窗口标题随语言切换（zh: OpenSteamTool 一键管理工具）。

## 保留的约束

kill-ai-slop 硬性约束继续生效：无渐变、毛玻璃、发光点、emoji、圆角嵌套、卡片套卡片、AI 文案腔。语言切换按钮为纯文字（EN/中文）。

## 未采纳的项

窗口尺寸保持可缩放 + 首帧自适应（旧版为固定 560×470），此为 ADR-0002 既定行为，不在本次外观对齐范围内回退。

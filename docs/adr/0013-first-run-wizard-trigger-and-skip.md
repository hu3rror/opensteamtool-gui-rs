# 首次运行向导：触发与跳过语义

全新安装没有 `config.toml`（ADR-0012），且「补丁未下载」是默认状态（ADR-0011），
需要语言与 Steam 路径的引导。决定：`wizard` 模块提供三步首次运行向导（语言 →
Steam 路径 → 补丁下载并解压），Settings — General 可随时以当前配置为初值重跑。

## 触发（`should_show`）

- 纯函数判据（路径注入，测试用临时目录）：`config.toml` 缺失、损坏/版本不符
  （启动已降级默认值，ADR-0012），或已存 `steam_path` 非有效目录（空 = 未设置）。
- 「有效 Steam 路径」判据与 `config`/`dll` 共用同一 `is_dir` 口径；除上述情形外
  一律不显示——正常启动不打扰老用户（「never otherwise」有测试兜底）。

## 步骤 3 不自动下载

进入步骤 3 停在 `Idle`，由用户显式点击「下载并解压」才开始（自动下载有入侵感，
#29 交互决定）；失败就地显示，可重试或跳过。

## 终局收敛（完成 / 跳过 / 关窗）

- 三终局收敛同一 `Finish` 效果：持久化语言与 Steam 路径、切回主界面；关窗从任意
  步骤都等同跳过（永不把用户锁在向导里），终局后忽略一切迟到事件（迟到的下载
  结果不复活向导、不重复持久化）。
- 跳过留下的「补丁缺失」是文件系统事实（`dlls/` 缺文件，ADR-0011），不由向导
  记录；主页面操作区按 ADR-0011 引导前往 Settings — General 补丁更新。
- 重跑向导以当前会话值播种，使重跑是「编辑」而非「重置」。

## 与更新流程的关系

向导步骤 3 的「检查 → 下载并解压」由 `wizard_download` 直连 `updater` 一次性
完成，不经 `update_flow` 单一事实源——向导只需要一个成败结果，不参与设置页的
补丁检查状态（ADR-0008 修订）。

## 验收

`wizard.rs` 单测覆盖：触发判据（缺文件/空路径/不存在目录/损坏/版本不符 → 显示；
有效路径 → 永不显示）、完整步进、无效路径停留、下载失败重试/跳过、跳过与关窗
收敛同终局、终局后事件忽略、在途下载去重；`cargo test --workspace` 全绿。

# 外观对齐 Python 版（Python-parity restyle）

原 Python 版（`opensteamtool-gui-py`）是最终用户的既有视觉基准，本次 Rust 版外观全面对齐其设计语言，替换 ADR-0002 中 Apple-inspired 的配色与组件形态。

## 决策

- **配色**：直接采用 Python 版 `THEME` 色板——面板 `#f8f9fa`、卡片白底 + `#e2e8f0` hairline 边框、accent 蓝 `#0f6cbd`、次按钮 `#f8fafc`、绿色主按钮 `#16a34a`（应用补丁并启动）、浅蓝描边 `#f0f9ff`/`#0284c7`/`#7dd3fc`（退出并卸载）、蓝实心 `#0284c7`（卸载并重启）。
- **卡片标题**：恢复 Python 版左侧 3px 蓝色 accent bar（`#0f6cbd`），替代原纯文字标题。
- **操作按钮区**：从卡片 2 内部移出，成为卡片 2 与卡片 3 之间的独立等宽双按钮区（效仿 Python `action_frame`）。
- **状态展示**：由「4px 圆点 + 词」徽章改为纯文字行——`【已应用】…`（绿）/ `【未应用】…`（灰），移除 Steam 运行状态徽章（运行与否仍通过按钮文案「退出 Steam 并卸载补丁 / 卸载补丁」体现）。
- **版本信息**：卡片 3 由胶囊标签（`value_tag`）改为 Python 式纯文本行（`当前本地版本：…` / `最新线上版本：…` + 状态后缀）。
- **文案**：状态术语统一「已应用/未应用」（见 CONTEXT.md）；按钮保留 ▶/◀ 前缀；窗口标题随语言切换（zh: OpenSteamTool 一键管理工具）。

## 保留的约束

kill-ai-slop 硬性约束继续生效：无渐变、毛玻璃、发光点、emoji、圆角嵌套、卡片套卡片、AI 文案腔。语言切换按钮不采用 Python 版的 🌐 emoji，保持纯文字（EN/中文）。

## 未采纳的项

窗口尺寸保持可缩放 + 首帧自适应（Python 版为固定 560×470），此为 ADR-0002 既定行为，不在本次外观对齐范围内回退。
